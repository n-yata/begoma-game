# 初期要求

> 壁打ちセッション（2026-08-19 開始）の成果物。確定した内容から都度追記する。

## 解決したい課題

（2026-08-19 確定）

- **メイン**: ブラウザでサッと開いて短時間で気持ちよく遊べる 3D ゲームを提供する。
  「開いて10秒で遊べて、1プレイ1分で気持ちいい」が北極星
- **副次**: 実物に触れる機会が減ったベーゴマ遊び（回して・ぶつけて・弾き出す）の
  楽しさを、ベーゴマを知らない世代にも伝える

## ターゲットユーザー

（2026-08-19 確定）

- **メイン**: カジュアルゲーマー。ベーゴマを知らなくてよい。
  PC・スマホのブラウザで暇つぶしに遊ぶ層
- **サブ**: ベーゴマに懐かしさを感じる世代、文化として興味を持つ人

## 主要機能

- **3D のベーゴマゲーム**（2026-08-19 確定）
  - 3D 表現でベーゴマの対戦を描く
- **対戦形態: vs CPU（一人プレイ）**（2026-08-19 確定）
  - MVP はサーバー不要の一人プレイに絞る
  - ローカル対戦は MVP 後の候補、オンライン対戦は将来の拡張案として保留
- **操作方式: ドラッグ投げ**（2026-08-19 確定）
  - 引っ張って離す。引いた方向と長さで投げる角度・強さが決まる
  - PC（マウス）・スマホ（タッチ）共通の操作系
- **勝敗条件: 弾き出し or 回転停止の両方**(2026-08-19 確定)
  - 相手を床（トコ）から弾き出したら勝ち
  - 双方場内なら、先に回転が止まった方が負け
- **1プレイの流れ**（2026-08-19 確定）
  - 投げる → 自動でぶつかり合いを見守る → 決着、の1ラウンド勝負がベース
  - 3本勝負などのラウンド制は後から拡張できる形にする
- **コマの種類: 固定3種から選択**（2026-08-19 確定）
  - 例: 重量型・速攻型・バランス型。ステータス（重さ・回転力など）で個性を出す
  - カスタマイズ（削り・改造）・収集・強化要素は MVP に含めない（将来拡張）


## MVP の範囲

（2026-08-19 確定）

### 入れるもの

- 3D の床（トコ）上でのベーゴマ物理対戦（vs CPU、1ラウンド勝負）
- ドラッグ投げ操作（PC マウス / スマホ タッチ共通）
- 勝敗判定: 弾き出し or 回転停止
- コマ選択（固定3種: 重量型・速攻型・バランス型 など）
- リザルト表示 → もう一度遊ぶ

### 入れないもの（将来拡張として保留）

- ローカル対戦・オンライン対戦
- コマのカスタマイズ（削り・改造）・収集・強化・レベルアップ
- ラウンド制（3本勝負）— ただし後から足せる構造にはしておく
- セーブデータ・戦績記録・ランキング

## 制約・前提

- **プレイ環境: ブラウザ（PC・スマホ両対応）**（2026-08-19 確定）
  - WebGL ベースの 3D 描画（Three.js / Babylon.js 等は今後選定）
  - URL 共有だけで遊べる配布の軽さを重視

## 未解決の論点（後続工程で決める）

- 3D 描画ライブラリの選定（Three.js / Babylon.js 等）と物理エンジンの選定
  → `architecture.md` 作成時（`/flow-setup-project`）に判断
- CPU の強さ・難易度設定の有無
- 効果音・BGM の扱い
- ホスティング先（静的ホスティングで足りる想定）
