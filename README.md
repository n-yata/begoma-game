# begoma-game（べーゴマバトル）

ブラウザで遊べる 3D ベーゴマ対戦ゲーム。ドラッグで投げ込み、物理シミュレーションで
ぶつかり合い、相手を弾き出すか先に回転を止めた方が勝ち。vs CPU の1ラウンド勝負。

## 遊び方

1. スタート → コマを3種（重量型・速攻型・バランス型）から選ぶ
2. 画面を**下に引っ張って離す**とトコ（椀状の床）へ投げ込む。引いた長さが強さになる
3. 相手を場外へ弾き出すか、相手より長く回り続けたら勝ち。トコに乗らなかったら投げ込み失敗で負け

## 開発

```bash
npm ci             # 依存インストール
npm run dev        # 開発サーバー (http://localhost:5173)
npm test           # ユニット＋統合テスト（カバレッジ付き）
npm run lint       # ESLint（レイヤー依存ルール含む）
npm run typecheck  # 型チェック
npm run build      # dist/ に静的ビルド
```
